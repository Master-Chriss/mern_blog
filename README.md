# MERN Blog - Modern Glassmorphism Blog Platform

A full-stack blog application built with the MERN stack (MongoDB, Express, React, Node.js) featuring a stunning glassmorphism UI, role-based authentication, and cloud image storage.

![Blog Screenshot](link-to-screenshot.png)

## ✨ Features

- 🎨 **Glassmorphism UI** - Modern, sleek design with backdrop blur effects
- 🔐 **Role-based Access** - Admin, Author, and Reader roles
- 📝 **Rich Text Editor** - Create and edit posts with Quill Editor
- 🖼️ **Cloud Image Storage** - Images stored on Cloudinary
- 🔍 **Instant Search** - Search posts by title, summary, or author
- 📱 **Fully Responsive** - Works on all devices
- 🌙 **Dark Theme** - Easy on the eyes
- 🗑️ **Admin Dashboard** - Manage users and content

## 🛠️ Tech Stack

**Frontend:**
- React 19
- React Router v6
- Tailwind CSS
- ReactQuill Editor
- React Hot Toast
- DOMPurify

**Backend:**
- Node.js
- Express
- MongoDB with Mongoose
- JWT Authentication
- Cloudinary
- Multer
